# UI and Interaction Specification

Use `desktop-reference.jpg` as the primary visual reference and `reference-styles.css` as measured clean-room styling guidance.

## Page states

### Initial Global state

- Heading: `Power leaderboard`
- Subtitle communicates Global top players by power.
- Filter card contains the label `Filter by State`.
- Input placeholder: `type a State ID...`
- Help text explains that an empty State ID returns the Global leaderboard.
- Start the live Global request on page load.

### Pending state

- Replace the result list with `Loading...`.
- Do not leave old State results displayed as though they belong to the pending query.
- A newer query cancels or supersedes the older one.

### Applied State state

- State input accepts digits, but typing alone does not apply the filter.
- Enter commits the State ID.
- Replace the input with one blue chip.
- Chip text displays the State ID.
- Chip remove control accessible name: `Remove State {id}`.
- Subtitle changes to `State {id}`.
- Results come from the live State endpoint.
- URL stays `/leaderboard/`.

### Removed State state

- Removing the chip restores the input.
- Immediately fetch the live Global leaderboard again.
- Show `Loading...` until the Global response arrives.

### Empty state

- Copy: `No ranked players.`
- Centered gray text.
- 32 px vertical and 16 px horizontal padding.

### Error state

- Clearly say the live data could not be loaded.
- Include Retry.
- Retry refetches the currently selected scope.
- Never substitute static fixture data or label stale rows as current.

## Row structure

Each row renders:

1. Rank as `#{rank}`.
2. Player name linked to `/player/{playerId}`.
3. Optional State linked to `/states/{stateId}`.
4. Relative-power bar.
5. Formatted power.
6. `Furnace {level}`.
7. Delta percentage or missing-value placeholder.

Null handling:

- Null nickname: `Player {uid}`.
- Null State: placeholder only, no link.
- Null delta: render the same missing-value placeholder used by the reference UI.

Power bar:

```ts
const maximum = Math.max(...rows.map((row) => row.power), 1);
const percent = Math.max(0, Math.min(100, (row.power / maximum) * 100));
```

The first row is 100 percent. Normalize again for every new result set.

Power formatting:

- Divide by one billion.
- Show up to two decimal places.
- Remove trailing zeroes.
- Examples: `18.68B`, `11.7B`, `6B`.

Delta formatting:

- The API value is fractional.
- Multiply by 100 before formatting.
- Preserve null as missing.

- White 60 px rail.

## Mobile layout

Breakpoint: 768 px.

At 768 px or below:

- Hide the desktop rail.
- Show a fixed 60 px bottom navigation plus safe-area inset.
- Each navigation item uses icon plus 11 px label.
- Rows wrap.
- Stats change from an end-aligned vertical column to a start-aligned wrapping horizontal group.
- Add content and footer padding so the fixed navigation does not cover content.
- Any cookie notice sits above the mobile navigation.

## Accessibility

- Distinct labels for main and footer navigation landmarks.
- Icon-only desktop actions have accessible names and titles.
- Active route uses `aria-current="page"`.
- Decorative SVGs use `aria-hidden="true"`.
- Filter input accessible name: `Add a State ID to filter`.
- Chip remove accessible name: `Remove State {id}`.
- Visible keyboard focus ring on every control.
- Enter applies the filter.
- Respect `prefers-reduced-motion`.
- Use logical CSS properties.
- Set `dir="rtl"` for Arabic locale support.

## Do not add

- Pagination
- Sort controls
- Player search
- Avatars
- Medals
- Gradients
- Decorative game artwork
- Fake update timestamps
- Static player-data fallback

The target is intentionally plain, light, and utility-focused.
